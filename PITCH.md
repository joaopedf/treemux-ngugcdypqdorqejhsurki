# Todo List App

A beautifully minimal todo list application that makes task management effortless. Built with Next.js 15 and shadcn/ui, this app features a clean gradient interface with smooth transitions and intuitive interactions. What sets it apart is its thoughtful UX design - hover-to-reveal delete buttons, keyboard shortcuts for quick entry, and a persistent task counter that keeps you motivated. Perfect for anyone who wants to stay organized without the clutter of complex productivity tools.
